# GTDataWorks homepage release

Rendered homepage and a free public dataset projected from GTD DataSet Factory Core. The ZIP includes ten synthetic cases, a dataset card, provenance, manifest, and the CDLA-Permissive-2.0 license. Five private evaluation cases and their answers are excluded.

Dataset version: 1.1.1. The CD-010 reference was corrected in the source branch before this release. These are deterministic synthetic reference episodes, not observed model performance.

The dataset license applies to the data in the ZIP. The website markup and branding have no separate open-source grant.
